# Nautilus Copy Path

A small Nautilus extension that adds **Copy Path** to the context menu for
files, folders, multiple selections, and the current folder background.

Multiple selected paths are copied one per line. The menu is available only
for local files.

## Requirements

- Nautilus 49 or another release providing the Nautilus 4.1 API
- Python 3
- `python3-nautilus`

On Ubuntu:

```sh
sudo apt install python3-nautilus
```

## Install

```sh
./install.sh
```

Reopen Files after installation.
